# 第 0 章 · 学习地图与前端三件套最小基础

> **这一章解决什么问题**：在读 Vue 之前，先建立「一个网页是怎么来的」这张地图，并把读 Vue 代码真正会用到的 HTML / CSS / JavaScript 最小必要集补齐。
>
> **学完标准**：打开本项目任意一个 `.vue` 文件，你能分清哪部分是 HTML、哪部分是 JavaScript，并且能看懂函数、对象、数组、箭头函数、`import/export` 这些基本写法。

---

## 一、先看全景：一个网页由三样东西组成

| 三件套 | 负责 | 类比 | 本项目落点 |
|---|---|---|---|
| **HTML** | 页面**结构**：有哪些元素，谁套在谁里面 | 房子的墙和房间 | `.vue` 的 `<template>` |
| **CSS** | 页面**样式**：颜色、大小、位置 | 装修 | `.vue` 的 `<style>` |
| **JavaScript（JS）** | 页面**行为**：点击后干什么、数据从哪来 | 水电和智能家居 | `.vue` 的 `<script>` |

一个 `.vue` 文件，就是把这三样装在同一个文件里：

```vue
<template>
  <!-- HTML：长什么样 -->
</template>

<script>
// JavaScript：怎么动
export default { ... }
</script>

<style>
/* CSS：怎么好看 */
</style>
```

本项目的 `src/views/conf/billRule/index.vue` 就是这种结构：`:1-168` 是模板，`:170-420` 是脚本，`:421-438` 是样式。

> 本章只需要你「看得懂」，不需要你「写得很漂亮」。真正的重点从第 1 章开始。

## 二、浏览器打开一个网页，到底发生了什么

用本项目的前端入口举例。

### 2.1 服务器先返回一个几乎空白的 HTML

`zxcm-ui/public/index.html:175-194`：

```html
<body>
  <div id="app">
    <div class="first-loading-wrp">
      ...
      系统加载中
    </div>
  </div>
</body>
```

这个文件里**没有合同页面、没有菜单、没有表格**，只有一个 `id="app"` 的空壳，以及一句「系统加载中」。

### 2.2 浏览器再加载 JS，由 JS 把页面画出来

Vue 的入口 `src/main.js:209-214`：

```js
new Vue({
  el: "#app",
  router,
  store,
  render: (h) => h(App),
})
```

`el: "#app"` 的意思是：**接管 index.html 里那个 `id="app"` 的 div**，把整个 Vue 应用渲染到它里面。原先的「系统加载中」会被替换掉。
这里的 `"#app"` 不是 Vue 自定义的语法，而是一个 **CSS 选择器字符串**。`#` 表示“按 `id` 属性查找”，所以 `#app` 就是：
 找到页面中 `id="app"` 的那个元素。等价于原生 JS 的：
document.querySelector("#app")  或  document.getElementById("app")
Vue 拿到这个元素后，就把它作为应用的挂载点，把 `App` 组件渲染进去。
多个 `id="app"`：Vue 通常不报错，会选第一个。
没有 `id="app"`：Vue 会报找不到挂载点。
正确做法：保证 `id="app"` 全局唯一，只保留一个。

### 2.3 页面跳转不再刷新整个网页

点左侧菜单时，浏览器地址变了，但页面并没有重新加载——Vue Router 只是把「内容区现在显示哪个组件」换掉。

这种「只有一个 HTML，页面由 JS 动态切换」的应用叫 **SPA（单页应用，Single Page Application）**。

```
传统多页应用：每点一个链接 → 服务器返回一个新 HTML → 整页刷新
SPA：         首次加载 HTML + JS → 后续只换组件 → 不刷新
```

**代价**：首次要下载较多 JS（本项目用路由懒加载解决，见第 5 章）。
**收益**：切页快；后端只返回 JSON，前后端彻底分离。

## 三、HTML 最小必要集

### 3.1 标签、属性、嵌套

HTML 由**标签（tag）**组成：

```html
<button type="primary" size="mini">新增</button>
```

拆开看：

| 部分 | 例子 | 含义 |
|---|---|---|
| 开始标签 | `<button ...>` | 元素开始 |
| 标签名 | `button` | 这是一个按钮 |
| 属性 | `type="primary"` | 给这个元素的配置 |
| 内容 | `新增` | 显示在元素里的文字 |
| 结束标签 | `</button>` | 元素结束 |

**嵌套**：标签可以套标签。

```html
<div>
  <span>姓名：</span>
  <input />
</div>
```

`<input />`、`<img />` 这类没有内容、自己闭合的标签，叫**自闭合标签**。

### 3.2 读项目时最常见的 HTML 元素

| 标签 | 作用 | 本项目例子 |
|---|---|---|
| `div` | 一个块级容器（最常用） | 页面分区 |
| `span` | 行内容器，常用于一小段文字 | `position/index.vue:21` |
| `button` | 按钮 | `position/index.vue:69-75` |
| `input` | 输入框 | 项目里多用 Element UI 的 `<el-input>` 替代 |
| `form` | 表单容器 | `position/index.vue:29` |
| `h2` / `h3` | 标题 | `position/index.vue:5` |
| `template` | 不渲染自身的「包装」，只用来分组 | `DictTag/index.vue:3` |

> **重要**：项目里大量出现 `<el-button>`、`<el-table>`、`<el-form>`，这些不是浏览器原生标签，而是 **Element UI 组件**（本质上是别人写好的 Vue 组件）。第 7 章会讲它怎么被装进来。

### 3.3 属性里的三种值

```html
<!-- 1. 普通字符串 -->
<el-button size="mini">新增</el-button>

<!-- 2. 布尔属性：写了就是 true -->
<el-table border> ... </el-table>

<!-- 3. Vue 的动态绑定：冒号开头，值是一个 JS 表达式 -->
<el-table :data="tableData"> ... </el-table>
```

第三种是 Vue 的核心写法之一，第 2 章会专门讲。现在只需要记住：**看到属性前面有 `:`，它的值不是字符串，而是一段要计算的 JS 代码**。

## 四、CSS 最小必要集

### 4.1 选择器与声明

```css
.pagination-container {   /* 选择器：类名为 pagination-container 的元素 */
  background: #fff;       /* 声明：背景白色 */
  padding: 32px 16px;     /* 内边距 */
}
```

| 选择器    | 写法    | 例子          |
| ------ | ----- | ----------- |
| 类选择器   | `.类名` | `.app-main` |
| id 选择器 | `#id` | `#app`      |
| 标签选择器  | `标签名` | `body`      |

### 4.2 项目里的作用域样式

`src/views/conf/billRule/index.vue:421`：

```vue
<style lang="scss" scoped>
```

- `lang="scss"`：用 SCSS 语法（可以用嵌套、变量，本项目 `sass` 版本见 `package.json`）。
- `scoped`：**这段样式只作用于当前组件**，不会污染别的页面。Vue 编译时会自动给元素和选择器加上唯一属性。

### 4.3 读布局只需要认识 flex 的四个词

```css
display: flex; /*是 CSS 中**开启 Flex 布局**的声明。它把元素变成“弹性容器”，其直接子元素自动成为“弹性项目”，按一行（或一列）排列，并能灵活分配空间。*/
justify-content: center;   /* 主轴居中 */
align-items: center;       /* 交叉轴居中 */
flex-direction: column;    /* 主轴改成纵向 */
```

`public/index.html:90-96` 的加载动画就用了这套。看不懂 CSS 不影响你读 Vue 逻辑，先认识「这是样式」即可。

## 五、JavaScript 最小必要集（重点）

Vue 代码里 90% 是 JavaScript。下面每一项都配一个最小例子和项目里的真实写法。

### 5.1 变量：`let` / `const` / `var`

```js
let count = 0      // 可以重新赋值
count = 1

const name = '张三' // 不能重新赋值（对象内容可以改）
```

项目里大量使用 `const`（`src/views/conf/billRule/index.vue:353` 的 `const id = row.id || this.ids`）和 `let`（`src/views/system/role/index.vue:746` 的 `for (let i = 0; i < treeList.length; i++)`）。

> `var` 是旧写法，作用域规则容易坑人；新代码优先 `const`，需要重新赋值时用 `let`。

### 5.2 数据类型：先认识这几种

```js
const s = '文本'          // string 字符串
const n = 10              // number 数字
const b = true            // boolean 布尔
const empty = null        // 空值（明确表示"没有"）
const notSet = undefined  // 未定义（变量声明了但没赋值）
const obj = { id: 1 }     // object 对象
const arr = [1, 2, 3]     // array 数组（本质也是对象）
const fn = function() {}  // function 函数
```

**`null` 和 `undefined` 的区别**（面试常问）：

| 值 | 含义 | 典型来源 |
|---|---|---|
| `undefined` | 未定义 | 声明未赋值、对象里不存在的属性、函数没返回值 |
| `null` | 空值 | 开发者主动表示「这里没有值」 |

项目里查询条件用 `undefined` 表示「用户没填」（`billRule/index.vue:222-229`），这样后端就不会收到这个字段。

### 5.3 条件判断的「真值/假值」

```js
if (value) { ... }
```

以下值会被当作 **false**：

```
false、0、''（空字符串）、null、undefined、NaN
```

其余都是 true（包括空数组 `[]`、空对象 `{}`）。

项目里常见：

```js
if (getToken() && !isToken) { ... }   // request.js:32
```

`getToken()` 返回字符串或 `undefined`，所以可以直接当条件用。

### 5.4 函数

```js
function add(a, b) {
  return a + b
}

const add2 = (a, b) => a + b   // 箭头函数，等价
```

项目里方法有两种常见写法：

```js
// 普通函数
getList() { ... }                    // 对象方法简写

handleNodeClick(data) { ... }        // position/index.vue:227

// 箭头函数：常用于回调
.then((response) => { ... })         // billRule/index.vue:293
```

### 5.5 `this`：最容易踩的坑

在 Vue 组件的方法里，`this` 指向**当前组件实例**，所以能拿到 `data` 和调用其它方法：

```js
methods: {
  getList() {
    this.loading = true          // 访问 data 里的 loading
    listBillRule(this.queryParams).then((response) => {
      this.billRuleList = response.rows   // 箭头函数里的 this 仍是组件
    })
  }
}
```

**规则**：

- 普通函数里的 `this` 取决于**谁调用它**；
- 箭头函数**没有自己的 `this`**，会沿用外层函数的 `this`；
- 所以在 `.then(function(response) { this.xxx })` 里 `this` 会丢，而`.then((response) => { this.xxx })` 不会。

项目里回调几乎都用箭头函数（`billRule/index.vue:293`、`position/index.vue:193`），就是为了保住 `this`。

### 5.6 对象

```js
const user = {
  name: '张三',
  age: 20,
  say() {
    return this.name
  }
}

console.log(user.name)   // '张三'
user.age = 21            // 修改属性
user.email = 'a@b.c'     // 新增属性
```

Vue 组件的整个配置就是一个大对象：

```js
export default {
  name: 'Position',
  data() { return { ... } },
  methods: { ... }
}
```

### 5.7 数组与最常用的方法

```js
const list = [1, 2, 3]

list.map(x => x * 2)          // [2, 4, 6]  每个元素变换，返回新数组
list.filter(x => x > 1)       // [2, 3]     过滤，返回新数组
list.some(x => x > 2)         // true       有一个满足就 true
list.every(x => x > 0)        // true       全部满足才 true
list.includes(2)              // true       是否包含
list.push(4)                  // 末尾加一个，原数组变化
list.splice(1, 1)             // 从下标 1 删 1 个，原数组变化
```

项目里：

```js
this.tableData = res.rows                       // 整体替换
this.ids = selection.map(item => item.id)        // 取每行的 id，billRule:339
permissions.some(v => v === permission)          // 权限判断，src/plugins/auth.js:56
this.currentData.ruleArray.splice(index, 1)      // 删除一行，billRule:288
```

### 5.8 模板字符串

const name = '张三'

### 5.9 解构与展开

```js
// 解构：从对象/数组里取值
const user = { name: '张三', age: 20 }
const { name, age } = user

// 展开：把对象/数组的成员铺开
const params2 = { ...params, pageNum: 1 }   // 复制后再覆盖

```

```js

```

### 5.10 `import` / `export`：文件之间怎么共享代码

```js
// a.js —— 导出
export function add(a, b) { return a + b }
export default { name: 'demo' }

// b.js —— 导入
import demo, { add } from './a'
```

- `export function xxx`：**具名导出**，导入时名字必须对上，用 `{}`；
- `export default xxx`：**默认导出**，导入时名字随便起，不用 `{}`。

项目里三种都常见：

```js
export function listBillRule(query) { ... }        // billRule.js:13 具名导出
export default service                              // request.js:172 默认导出
import request from '@/utils/request'               // 默认导入
import { listBillRule } from '@/api/conf/billRule'  // 具名导入
```

`@` 是 `src/` 的别名（第 7 章讲）。

### 5.11 异步与 Promise（先混个脸熟）

发请求需要时间，JS 不会停在那里等：

```js
listBillRule(params)
  .then(res => {
    this.tableList = res.rows
  })
  .catch(err => {
    console.error(err)
  })
```

- `.then` 里是**成功之后**要做的事；
- `.catch` 里是**失败之后**要做的事；
- 第 1 章会再用到，第 7 章系统讲。

### 5.12 DOM：Vue 要替代的那套写法

浏览器把 HTML 解析成一棵「DOM 树」，传统写法用 JS 直接操作它：

```js
document.getElementById('app').innerHTML = '你好'
document.querySelector('.title').textContent = '新标题'
```

**Vue 的核心价值**：你不再手动改 DOM，而是只改数据，Vue 帮你把界面更新到最新状态。

```js
// Vue 写法
this.title = '新标题'    // 界面上用到 title 的地方自动更新
```

这句话是整套 Vue 的地基，第 1 章会展开。
