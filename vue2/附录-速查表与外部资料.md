## 三、生命周期速查

```
beforeCreate   实例初始化，data/methods 还不可用
    ↓
created        data/methods/computed 可用；DOM 未生成
    ↓
beforeMount    模板编译完成，尚未挂载
    ↓
mounted        DOM 挂载完成；可操作 DOM
    ↓
beforeUpdate   数据变化，DOM 更新前
    ↓
updated        DOM 更新后（不要在里面对数据再做修改）
    ↓
beforeDestroy  实例销毁前；清理定时器/事件
    ↓
destroyed      实例销毁后
```

keep-alive 额外：

```
activated      被缓存组件激活（首次也会触发）
deactivated    被缓存组件停用（不会 destroy）
```

父子顺序：

```
初次渲染：父 beforeCreate → 父 created → 父 beforeMount
        → 子 beforeCreate → 子 created → 子 beforeMount → 子 mounted
        → 父 mounted

更新：父 beforeUpdate → 子 beforeUpdate → 子 updated → 父 updated

销毁：父 beforeDestroy → 子 beforeDestroy → 子 destroyed → 父 destroyed
```

## 四、Vue Router 3 速查

### 4.1 创建

```js
import Vue from 'vue'
import Router from 'vue-router'
Vue.use(Router)

const router = new Router({
  mode: 'history',          // 或 'hash'
  base: '/',
  scrollBehavior: () => ({ y: 0 }),
  routes: [
    { path: '/login', component: Login },
    {
      path: '/system',
      component: Layout,
      redirect: '/system/user',
      children: [
        {
          path: 'user/:id?',
          name: 'User',
          component: () => import('@/views/system/user'),
          meta: { title: '用户管理', noCache: false }
        }
      ]
    },
    { path: '*', redirect: '/404' }
  ]
})
```

### 4.2 路由对象字段

| 字段 | 作用 |
|---|---|
| `path` | 路径，支持 `:id` 动态参数 |
| `name` | 命名路由，`params` 跳转必需 |
| `component` | 组件或 `() => import(...)` |
| `components` | 命名视图（`<router-view name="x">`） |
| `redirect` | 重定向 |
| `children` | 子路由 |
| `meta` | 自定义元信息（`title/noCache/activeMenu`） |
| `props` | 把路由参数作为 props 传入组件 |
| `alias` | 别名 |
| `beforeEnter` | 路由独享守卫 |

### 4.3 跳转与读取

| 写法 | 含义 |
|---|---|
| `this.$router.push('/a')` | 追加历史记录 |
| `this.$router.push({ path: '/a', query: { id: 1 } })` | 带 query |
| `this.$router.push({ name: 'Detail', params: { id: 1 } })` | 带 params |
| `this.$router.replace(...)` | 替换当前历史记录 |
| `this.$router.go(-1)` | 后退 |
| `this.$route.path` | 当前路径 |
| `this.$route.query` | query 参数 |
| `this.$route.params` | params 参数 |
| `this.$route.meta` | 路由元信息 |
| `this.$route.matched` | 匹配到的路由记录数组 |

### 4.4 守卫

```js
router.beforeEach((to, from, next) => {
  // to/from 是 Route 对象
  next()                 // 放行
  // next(false)         中断
  // next('/login')      跳转
  // next({ ...to, replace: true })  重新进入
})
router.afterEach((to, from) => {})
```

| 守卫 | 位置 |
|---|---|
| `beforeEach` / `beforeResolve` / `afterEach` | 全局 |
| `beforeEnter` | 路由配置 |
| `beforeRouteEnter` | 组件内（此时 `this` 不可用） |
| `beforeRouteUpdate` | 组件内（路由复用） |
| `beforeRouteLeave` | 组件内（离开） |

### 4.5 项目里的三条关键路由机制

1. **动态路由**：登录后 `getRouters` 返回菜单 → `filterAsyncRouter` → `router.addRoutes`（`store/modules/permission.js:75-224`）；
2. **刷新重进**：守卫里 `roles.length === 0` 时重建路由，再 `next({ ...to, replace: true })`（`src/permission.js:88-117`）；
3. **刷新中间站**：`/redirect/:path*` 路由 + `redirect.vue`（`router/index.js:33-43`、`views/redirect.vue:3-7`）。

## 六、请求层速查（本项目）

### 6.1 一个接口的标准写法

```js
// src/api/xxx/yyy.js
import request from '@/utils/request'

export function listYyy(query) {
  return request({
    url: '/xxx/yyy/list',
    method: 'get',
    params: query
  })
}

export function getYyy(id) {
  return request({ url: '/xxx/yyy/' + id, method: 'get' })
}

export function addYyy(data) {
  return request({ url: '/xxx/yyy', method: 'post', data })
}

export function updateYyy(data) {
  return request({ url: '/xxx/yyy', method: 'put', data })
}

export function delYyy(id) {
  return request({ url: '/xxx/yyy/' + id, method: 'delete' })
}
```

### 6.2 `params` 和 `data` 的区别

| 参数 | 出现在 | 适用 |
|---|---|---|
| `params` | URL query string | GET 查询 |
| `data` | 请求体 | POST/PUT |

### 6.3 响应结构

后端统一返回：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {},
  "rows": [],
  "total": 0
}
```

拦截器 `return res.data`，所以页面拿到的是这个 JSON 本身：

```js
.then(res => {
  this.tableData = res.rows
  this.total = res.total
})
```

## 九、npm 与运行命令

```bash
# 进入前端目录
cd zxcm-ui

# 安装依赖
npm install

# 开发（默认端口见 vue.config.js:12）
npm run dev

# 生产构建
npm run build

# 构建并输出到指定目录（脚本里定义了 build:prod 等时以 package.json 为准）
```

**本机注意**：

- 多版本 Node 环境，npm 命令前需要把目标 Node 放到 PATH 最前（见项目环境笔记）；
- webpack 4 在 Node 17+ 下可能报 `ERR_OSSL_EVP_UNSUPPORTED`，项目脚本已加 `NODE_OPTIONS=--openssl-legacy-provider`（`package.json:8`）；
- 改了 `vue.config.js` / `.env` 必须重启。

### 10.5 「Vue 2 已停止维护」怎么看

Vue 2 已于 **2023-12-31** 停止官方维护。本项目锁在 Vue 2.6.12 是历史原因（RuoYi 系 4.x 血统）。学习时注意：

- 官方文档可能不再更新，但内容仍然有效；
- 新项目应选 Vue 3 + Vite + Pinia；
- 面试时如果被问「为什么还用 Vue 2」，可以从「存量项目迁移成本、生态依赖（Element UI）、团队熟悉度」角度回答，同时说明你了解 Vue 3 的差异。

## 十二、最后：一张「遇到问题先做什么」的卡片

```
报错？
 ├─ 有红字 → Console 看第一条，点堆栈找自己的文件行
 ├─ 没红字但页面空
 │   ├─ Network 有请求吗？→ 没有：检查触发条件/事件
 │   ├─ 有请求 → 看 URL/参数/状态码/响应
 │   ├─ 响应对 → Devtools 看组件 data 有没有赋值
 │   └─ data 对 → 看模板绑定（v-if/v-for/prop）
 └─ 数据对但页面不更新
     ├─ 是不是新增属性/数组下标 → $set/splice
     ├─ 是不是异步时序 → $nextTick
     └─ 是不是缓存页 → activated / redirect
```

> **最后一句**：这套文档的价值不在「读完」，而在「读完能自己打开 `zxcm-ui` 的任何文件讲下去」。从今天开始，每读一个页面，就按第 9 章的五步法走一遍，一个月后你会发现自己不再害怕任何 `.vue` 文件。
