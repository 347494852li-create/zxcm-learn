## 阅读方法

1. **第一次读**：从第 0 章顺序往下读。每章的「新概念」只在**第一次出现的那一章讲透**，其它章只给一句回顾 + 指路。
2. **开发时**：跳到对应功能章，从「四、功能怎么实现（带着你复制）」开始照着敲；卡住回看「三、需要哪些技术」找精确位置。
3. **面试前**：先翻每章末尾的「本章答辩卡」（3 组追问级问答），再翻「六、面试高频问题」和「七、选型对比」。

## 定位约定

本套文档里，凡提到文件/技术/章节，都写成能直接找到的形式：

- **文件** → 全路径 + 行号，如 `zxcm-contract/src/main/java/com/ruoyi/conf/controller/TSigningSubjectController.java:77`
- **章节** → 「第 X 章 §Y.Z」
- **表** → 表名 + 谁建的，如 `conf_signing_subject`（肇新原作者建的）
