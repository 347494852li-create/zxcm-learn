# 基座重塑版 · 导航

> **配套学习文档**：[学习作战室](../学习作战室.md)（计划/打卡）、[合同生命周期与业务必修](../附录-合同生命周期与业务必修.md)（业务全景）、[运行与调试手册](../附录-运行与调试手册.md)（跑项目/排错）、[答辩作战手册](../附录-答辩作战手册.md)（讲稿/追问）。

> 这套文档是**基座（框架底座）开发与答辩手册**，按「**基座的每一块能力**」分章，每章固定 **9 段结构**（做什么 / 为什么这么设计 / 需要哪些技术 / 怎么实现 / 一个操作的完整生命流程 / 面试题 / 选型对比 / 延伸阅读 / 小结与下一步）。
>
> **「基座」= `ruoyi-base`**（`ruoyi-common` / `ruoyi-framework` / `ruoyi-system` / `ruoyi-tenant` / `ruoyi-generator`）**+ `ruoyi-admin` 启动壳**。业务模块（`zxcm-*`）在这一卷里只作为「基座的使用者」出现。
>
> 与另两卷的分工：**后端重塑版**讲「一条合同的业务生命周期」，**前端重塑版**讲「一个页面怎么跑」，**本卷**讲「业务之下的那层通用能力是怎么造出来的」——**它是前两卷的地基**。
>
> **2026-10-18 升级版**：全卷逐条核对了 `文件:行号` 引用；每章新增「零基础先补概念」「逐行读代码」「动手验证」「本章答辩卡」四块。升级中又发现 4 处新缺口（数据权限 `elseSql` 死分支、空列默认放行、乐观锁未启用、Excel 导入非原子），已并入[附录 A §五](附录A-基座横切索引.md)。

## 这一卷讲什么

**本卷重点**：**权限控制**（第 1~4 章，认证 → 鉴权 → 数据权限）与**多点登录**（第 5 章）——这两块深挖到「能改、能讲」；其余框架能力（多租户、ORM、日志、防重限流、脱敏、异常、缓存、文件、WebSocket……）**也各自成章**（第 6~14 章）；最后**第 15 章把它们合起来用**（从零加一个新模块）。

**深度目标**：**读懂 + 能改 + 答辩说得清**。

## 阅读方法

1. **第一次读**：从第 0 章顺序往下读。每章的「新概念」只在**第一次出现的那一章讲透**，其它章只给一句回顾 + 指路（**同一条能力只深讲一次**）。
2. **开发时**：想加某个能力，先查[附录 A · 基座横切索引](附录A-基座横切索引.md)「我要找 X → 去第几章」，再跳到对应章节。
3. **面试前**：先翻每章末尾的「本章答辩卡」（3 组追问级问答），再翻「六、面试高频问题」+「七、选型对比」，最后对照[附录 A §五](附录A-基座横切索引.md)（**46 处坦白点**）过一遍。
4. **想继续深挖**：看[附录 B · 框架学习路线图](附录B-框架学习路线图.md)——网上资料「先学什么后学什么」的四阶段路线。

## 定位约定

本套文档里，凡提到文件/技术/章节，都写成能直接找到的形式：

- **文件** → 项目根相对全路径 + 行号，如 `ruoyi-base/ruoyi-framework/src/main/java/com/ruoyi/framework/config/SaTokenConfig.java:55`
- **章节** → 「第 X 章 §Y.Z」
- **表** → 表名（+ 建表行号，脚本 `script/sql/zxcm_init.sql`）

> ⚠️ **版本红线（第 0 章 §3.2）**：网上 RuoYi-Vue-Plus 教程大多是 **5.x**（`org.dromara` / `jakarta.*` / JDK 17），本仓库是 **`4.0.1s`**（`com.ruoyi` / `javax.*` / JDK 11）。**学思想不抄代码**——本卷每一处 `file:line` 都是答案册里真实存在的，这是你对照学习的锚点。
