## 四、任意行号怎么换算

注释是**多处插入**的，不能用一个固定偏移量。两种可靠方法：

### 方法 1：搜 `★`（最推荐）

打开注释版文件，搜索 `★`，每条教学注释都以它开头。你要找的代码就在对应 `★` 注释下面。

### 方法 2：用 diff 计算

在 `E:\Develop\project\zxcm-learn` 执行：

```bash
git diff --unified=0 -- zxcm-ui/src/utils/request.js
```

`@@ -旧行,0 +新行,数量 @@` 表示在旧行后插入了若干行；把插入行数累加，就是新行号。

### 方法 3：用仓库里的换算脚本

```bash
cd E:\Develop\project\zhaoxin
python tools/frontend-line-map.py src/utils/request.js 19 27 32-34 71
```

输出示例：

```text
19 -> 54
27 -> 74
32 -> 92
33 -> 93
34 -> 94
71 -> 183
```
