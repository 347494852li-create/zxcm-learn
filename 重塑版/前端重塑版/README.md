## 阅读方法

1. **第一次读**：从第 0 章顺序往下读。第 0~3 章讲**机制**（请求层、路由权限、通用组件），是全站的公共底座；第 4~10 章讲**具体页面族**。
   **完全零基础**：先读[附录 B](附录B-零基础精读：一次请求的完整流程.md)，跟着一次真实请求把 URL、axios、环境变量、代理、Vue 基础过一遍，再回第 0 章。
   如果连 Vue 本身都没学过（模板语法、组件、路由、Vuex 都陌生），**先读[精读 2 · 代码导读](精读篇/02-代码导读-逐行读懂vue.md) 的 §0~§4**——那里用前端自己的话把读项目所需的语法补齐了。
2. **答辩前**：先翻每章末尾的「本章答辩卡」（3 组追问级问答），再翻「六、面试高频问题」和「七、选型对比」，最后对照附录的横切索引。
3. **要改某个页面时**：跳到对应页面族那一章，从「四、页面怎么读怎么改」找到文件路径 + 行号，回答案册对照。

## 定位约定

本套文档里，凡提到文件/技术/章节，都写成能直接找到的形式：

- **前端文件** → 相对 `zxcm-ui/` 的全路径 + 行号，如 `zxcm-ui/src/views/conf/signingSubject/index.vue:793`
- **后端接口** → HTTP 方法 + 路径，如 `POST /contract/contractAudit/uploadSealContract`
- **章节** → 「第 X 章 §Y.Z」；前端与后端互相指路时写「见《后端重塑版》第 X 章」

## 前端 vs 后端：同一件事的两种视角

后端重塑版按「合同生命周期」切；前端重塑版按「你在屏幕上看到的页面族」切。两条线是这样对上的：

| 做的事 | 后端章节 | 前端章节 |
|---|---|---|
| 签约主体 / 合作方 / 编号 / 合同类型 | 第 1~4 章 | 第 4 章 |
| 合同草拟、上传文件、版本 | 第 5 章 | 第 5 章 |
| 审批、用印、作废、续签、归档 | 第 6、9 章 | 第 6 章 |
| 模板体系 | 第 7 章 | 第 7 章 |
| 文档生成 / 在线编辑 | 第 8 章 | 第 8 章 |
| 报表看板 | 第 10 章 | 第 9 章 |
| 工作流 | 第 6 章 | 第 10 章 |

> 前端章节号与后端**不完全对齐**（后端把「用印作废」单列第 9 章、前端把它并进第 6 章审批收尾），因为两边的「一件事」边界不同——后端按数据生命周期切，前端按页面归属切。
