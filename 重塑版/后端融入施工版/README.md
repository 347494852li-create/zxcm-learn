## 和原目录的关系

| 目录 | 定位 |
|---|---|
| `../后端重塑版/` | 学习版：需求、设计、表、施工步骤 |

## 每章的结构

```
一、这部分是做什么的
二、为什么这么设计
三、需要哪些技术
四、功能具体怎么实现
    4.1 需求 + 拆解 + 表设计导读 + 施工计划
    4.2 ~ 4.N  按业务动作 / 技术专题分步施工（每节有目标 / 验收）
    4.N+1 前端页面
    4.N+2 复制清单与必改
    4.N+3 跑通验证
    4.N+4 坑
    4.N+5 没考虑周全的地方 / 任务步骤
五、接口文档
    5.1 ~ 5.N  逐接口请求 / 响应
    5.N+1 逐接口示例
六、面试
七、选型
```

> 章节不同，4.x / 5.x 的编号会不一样；**同名小节只会有一份**（施工单里的前端/复制/坑会并进已有小节）。

## 怎么用

1. **学**：读 §一~§四，重点是「表设计导读」和「为什么这么设计」；
2. **敲**：按 §四 的分步目标走，复制清单在 4.x「复制清单」；
3. **联调**：§五 有每个接口的请求 / 响应；
4. **排错**：先看 4.x「坑」，再看对应小节；
5. **面试**：§六 + 表设计导读末尾的面试答法。
